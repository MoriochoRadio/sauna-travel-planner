# 온기행 (Ongihaeng)

> 한국의 사우나·찜질방·온천을 취향, 근거, 여행 맥락으로 연결하는 웰니스 여행 플랫폼입니다.

## 서비스 바로가기

**[온기행 최신 서비스 열기](https://saunatravel-avlgzg9u.manus.space)**

현재 링크는 최신 배포 버전을 가리킵니다. 장소 운영 시간·요금·이용 조건은 변동될 수 있으므로, 각 장소의 공식 출처도 함께 확인해 주세요.

## 제공 기능

| 영역 | 주요 기능 |
|---|---|
| 탐색 | 지역·분위기·시설·예산·동행 유형 기반 장소 탐색 |
| 여행 설계 | AI 코스, 지도 동선, 날짜·예산·체크리스트를 포함한 개인 플래너 |
| 공유 | 토큰 기반 읽기 전용 여행 플랜 링크 |
| 신뢰 정보 | 공식 출처, 검증일, 이용 팁과 여행 가이드 |
| 운영 | 관리자 전용 장소 검증, 사용자 플랜 상태·공유·내부 메모 관리 |

## 기술 구성

React 19, TypeScript, Vite, Express, tRPC, Drizzle ORM, MySQL/TiDB, Tailwind CSS 기반으로 구성했습니다. 로그인 기반 개인화와 역할 기반 관리자 권한을 제공합니다.

## 로컬 실행

```bash
pnpm install
pnpm dev
```

검증 명령은 다음과 같습니다.

```bash
pnpm check
pnpm test
pnpm build
```

## 최신 검증 상태

최신화 기준으로 타입 검사, 21개 자동 테스트, 프로덕션 빌드, 프로덕션 의존성 보안 감사를 통과했습니다. 상세 QA 근거와 서비스 준비 판단은 [`docs/`](./docs)에서 확인할 수 있습니다.
