# 온기행 (Ongihaeng)

> 한국의 사우나·찜질방·온천을 취향, 근거, 여행 맥락으로 연결하는 웰니스 여행 플랫폼입니다.

## 서비스 바로가기

**[온기행 GitHub Pages 정적판 열기](https://moriochoradio.github.io/sauna-travel-planner/)**

현재 공개 링크는 서버 없이 동작하는 GitHub Pages 정적판입니다. 장소 탐색, 여행 가이드, 공식 정보 이동, 브라우저 내 여행 목록을 제공합니다. 로그인·AI 코스·서버 저장·공유 링크·관리자 기능은 풀스택 소스에 보존되며, 정적판에서는 제공하지 않습니다. 장소 운영 시간·요금·이용 조건은 변동될 수 있으므로, 각 장소의 공식 출처도 함께 확인해 주세요.

## 제공 기능

| 영역 | 주요 기능 |
|---|---|
| 탐색 | 지역·분위기·시설·예산·동행 유형 기반 장소 탐색 |
| 여행 설계 | 정적판: 브라우저 내 장소 목록 · 풀스택 소스: AI 코스, 지도 동선, 날짜·예산·체크리스트 |
| 공유 | 풀스택 소스에서 토큰 기반 읽기 전용 여행 플랜 링크 제공 |
| 신뢰 정보 | 공식 출처, 검증일, 이용 팁과 여행 가이드 |
| 운영 | 풀스택 소스에서 관리자 전용 장소 검증, 사용자 플랜 상태·공유·내부 메모 관리 |

## 기술 구성

React 19, TypeScript, Vite, Express, tRPC, Drizzle ORM, MySQL/TiDB, Tailwind CSS 기반으로 구성했습니다. 로그인 기반 개인화와 역할 기반 관리자 권한을 제공합니다.

## 로컬 실행

```bash
pnpm install
pnpm dev
```

검증 명령은 다음과 같습니다.

```bash
pnpm check
pnpm test
pnpm build
```

## 최신 검증 상태

최신화 기준으로 타입 검사, 25개 자동 테스트, 프로덕션 빌드, 프로덕션 의존성 보안 감사를 통과했습니다. 상세 QA 근거와 서비스 준비 판단은 [`docs/`](./docs)에서 확인할 수 있습니다.
