# PRD — 사우나 중심 여행 추천 웹앱 (Sauna Travel Planner)

> 버전: v0.1 (Phase 0 초안) · 날짜: 2026-07-09

## 1. 배경 (Background)
한국은 사우나·찜질방·온천 문화가 매우 발달되어 있고, 지역마다 특색 있는 핫스팟(강원 온천, 부산 바다 찜질방, 경주 힐링 온천 등)이 존재한다. 하지만 "사우나를 중심으로" 맛집과 볼거리를 하나의 여행 코스로 묶어주는 서비스는 부족하다. 사용자는 직접 여러 앱을 뒤져 동선을 짜야 하는 불편이 있다.

## 2. 목표 사용자 (Target Users)
- **주말 힐링 여행객**: 직장인/커플/친구 모임으로 주말 1~2일 치유 여행을 원하는 사람
- **사우나 매니아**: 지역 사우나·온천을 여행 목적지로 삼는 사람
- **여행 초보**: 동선 설계에 익숙하지 않아 "그냥 코스만 줘" 하는 사람

## 3. 핵심 가치 (Core Value)
- 사우나/찜질방/온천을 **축**으로, 맛집·볼거리를 **보조**로 묶은 밸런스 좋은 여행 코스
- "지역 / 기간 / 취향"이라는 적은 입력으로 완성된 일자별 타임라인 제공
- 웰니스 강조(수분·휴식·과열 주의)를 기본에 녹인 건강한 설계

## 4. 주요 기능 (MVP Scope)
1. **입력 폼**: 지역 선택, 기간(1~4일), 취향 다중선택(조용한/가성비/프리미엄/가족/혼자/야외온천/음식중심), 특이사항 자유텍스트
2. **AI 코스 생성**: 입력 기반으로 LLM이 일자별 타임라인 생성 (장소·시간·추천이유·팁·예상비용)
3. **결과 뷰**: 일자별 카드 UI, 모바일 반응형, 다시 생성 버튼
4. **폴백 생성**: LLM 키 누락/실패 시 규칙 기반 기본 코스로 항상 동작
5. **데이터 기반**: curated seed 데이터(지역별 사우나·맛집·볼거리)를 추천 근거로 사용

## 5. 범위 밖 (Non-goals, v1)
- 실시간 예약/결제 연동
- 실시간 크롤링/리뷰 집계 (v1은 정적 seed, 후속 자동화로 보강)
- 사용자 계정/로그인/저장소
- 다국어 (v1 한국어만)

## 6. 성공 지표 (Success Metrics)
- 코스 생성 성공률 ≥ 95% (폴백 포함)
- 주요 지역 5곳 × 장소 8개 이상 커버
- 첫 입력~결과 표시 < 15초 (LLM 정상 시)
- 모바일에서 입력→결과 흐름 정상 동작

## 7. 제약 (Constraints)
- 서버리스 무료 호스팅 (Vercel/Cloudflare) — API 키 클라이언트 노출 금지
- LLM은 무료 모델 사용 (OpenRouter `nousresearch/hermes-3-llama-3.1-405b:free` 등)
- 코드는 GitHub 저장소에, CI로 lint/typecheck/test 자동화

## 8. 향후 로드맵 (Out of Scope → Next)
- 공공데이터포털 tourAPI 연동으로 장소 자동 보강
- 지도 시각화(이동 동선)
- 사용자 코스 공유/북마크
- 계절/날씨 기반 추천
