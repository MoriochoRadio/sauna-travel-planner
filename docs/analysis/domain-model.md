# 도메인 분석 (Domain Analysis)

> Phase: Analysis · 문서 버전: v0.1 · 날짜: 2026-07-09
> 주제: 사우나 중심 여행 코스 설계의 도메인 규칙

## 1. 도메인 개념

- **사우나/찜질방(sauna/jjimjilbang)**: 고온 건식·습식, 체류 2~4시간, 보통 하루 1회
- **온천/spa**: 수온 낮고 장시간 가능, 야외(outdoor_spa)는 프리미엄·계절 소구
- **맛집(restaurant)**: 사우나 전(가벼운)·후(보양/해장) 양쪽 배치 가능
- **볼거리(attraction)**: 사우나 사이 완충(휴식) 또는 오후 산책 코스

## 2. 코스 설계 규칙 (도메인 제약)

| 규칙 | 이유 | 적용 |
|------|------|------|
| R-1 사우나는 하루 1회, 오전 또는 저녁 집중 | 과열·탈수 방지 | 폴백/LLM 가이드 |
| R-2 사우나 전후 수분·휴식 버퍼 | 웰니스 안전 | Stop 사이 간격 |
| R-3 맛집은 점심·저녁에 배치 | 식사 리듬 | 시간대 매핑 |
| R-4 볼거리는 사우나 사이 완충 | 피로 분산 | 오후 배치 우선 |
| R-5 야외온천은 취향 선택 시 우선 + 계절 언급 | 소구 정확도 | outdoor_spa 가중 |
| R-6 가성비 취향 시 priceLevel low/mid 우선 | 비용 정렬 | budget 가중 |
| R-7 프리미엄 취향 시 high 우선 + 노천/뷰 강조 | 경험 품질 | premium 가중 |

## 3. 웰니스 원칙 (안전/건강)

- 과열 주의: 한 세션 15~20분 × 2~3회, 사이 냉각·수분
- 수분: 세션당 500ml 권장, 코스 summary에 수분 멘트
- 휴식: 사우나 직후 즉시 이동보다 20~30분 휴식 권장

## 4. 시간대 템플릿 (폴백 기준)

```
Day 기본 루프 (1일):
  10:00  사우나/온천  (2~3h)
  13:00  점심 맛집    (1h)
  14:30  볼거리      (1~2h, 완충)
  17:00  저녁 맛집    (1~1.5h)
  19:00  사우나/찜질방 야간 (선택, 단일일정 시 생략 가능)
```

## 5. 용어 정의

- **Stop**: 코스 내 하나의 방문 노드(장소+시간+이유+팁)
- **Day**: 연속된 Stop들의 묶음, 테마 보유
- **코스(Course)**: Day들의 배열 + 예상비용 + 요약
