# 콘텐츠·가이드 화면 검토

홈, 가이드 목록, 부산 가이드 상세, 장소 상세를 데스크톱에서 검토했다. 홈에는 기존 탐색·AI 코스 흐름을 방해하지 않는 위치에 가이드 섹션이 추가됐으며, 3개 가이드는 제목·읽기 시간·진입 동작을 명확히 드러낸다. 가이드 상세는 준비물, 단계별 본문, 연결 장소를 하나의 세로 흐름으로 구성해 모바일에서도 읽기 부담을 줄이는 구조다.

장소 카드에는 `공식 정보 확인` 또는 `큐레이션 초안`과 검증일을 함께 표시했고, 장소 상세에는 출처 링크와 방문 전 재확인 안내를 별도 신뢰 정보 영역으로 제공한다. 지도 공급자나 인증 데이터가 지연되는 환경에서는 개인 여행 화면이 로딩 상태를 먼저 표시하며, 데이터 응답 뒤 플래너 편집 UI를 렌더링하도록 설계되어 있다.

다음 QA 단계에서는 실제 로그인 세션에서 날짜·예산·체크리스트·공유 링크의 저장과 공개 링크의 읽기 전용 표시를 검증한다.
