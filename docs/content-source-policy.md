# 장소 콘텐츠 출처 및 검증 정책

## 원칙

온기행은 시설의 영업시간, 요금, 이용 조건, 접근성, 예약 경로처럼 방문 의사결정에 직접 영향을 주는 정보를 **공식 운영사 또는 공공 관광기관 출처**에서만 반영한다. 제휴·사용자 생성 콘텐츠·검색 결과만으로 운영 정보를 확정하지 않으며, 확인할 수 없는 정보는 노출하지 않는다.

| 정보 유형 | 우선 출처 | 화면 노출 원칙 |
|---|---|---|
| 운영 시간·요금·휴무·연락처 | 시설 공식 사이트 | 원문 바로가기와 검증일을 함께 표시한다. |
| 주소·교통·접근성 | 공식 사이트 또는 지방 관광기관 | 출처 링크와 함께 짧은 방문 팁으로 요약한다. |
| 시설·테마·이용 규정 | 시설 공식 사이트 | 확인 가능한 사실만 태그와 안내로 구조화한다. |
| 주변 여행 연결 | 공공 관광기관 또는 해당 명소 공식 사이트 | 장소 간 이동 시간·거리 등 실시간성이 큰 수치는 출처 없이는 고정값으로 쓰지 않는다. |
| 건강·과학 콘텐츠 | 학술 데이터베이스·공신력 있는 연구기관 | 질병 치료·효능 보장 표현을 금지하고, 일반 정보·안전 주의로 한정한다. |

## 검증 상태 표기

장소 상세에는 `공식 정보 확인`, `검증일`, `공식 사이트`를 일관되게 표시한다. 운영 정보는 바뀔 수 있으므로 사용자가 방문 직전에 공식 사이트를 다시 확인하도록 명시한다. 아직 출처가 보강되지 않은 카탈로그 항목은 `큐레이션 초안` 상태로만 노출하고, 예약·요금 등 행동을 유도하는 정보는 제공하지 않는다.
