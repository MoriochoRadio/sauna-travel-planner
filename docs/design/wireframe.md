```
┌─────────────────────────────┐
│  🔥 사우나 여행 코스 메이커  │
│  지역을 축으로 한 맞춤 여행  │
├─────────────────────────────┤
│ 지역                          │
│ [ 서울 ▼ ]  (드롭다운)        │
├─────────────────────────────┤
│ 기간                          │
│ ( 1 ) ( 2●) ( 3 ) ( 4 )      │  ← 세그먼트 선택
├─────────────────────────────┤
│ 취향 (복수 선택)              │
│ [조용한][가성비][프리미엄]    │
│ [가족][혼자][야외온천][음식]  │  ← chip 토글

│ ┌─────────────────────────┐ │

├─────────────────────────────┤
│   [ 코스 만들기 ]  (CTA)     │  ← 버튼 ≥44px
└─────────────────────────────┘
```

## 디자인 토큰 (사우나 무드)
- 배경: 따뜻한 크림 `#FBF6EF`
- 포인트: 온천 오렌지 `#E8743B`
- 텍스트: 진한 갈색 `#3A2E26`
- 카드: 화이트 + soft shadow
- 폰트: 시스템 산세리프 (한글 가독성)
- 반응형: 모바일 1열 → 데스크톱 2열(입력/결과 분할 가능)
- a11y: 폼 label 명시, 버튼 터치 ≥44px, 콘트라스트 AA
