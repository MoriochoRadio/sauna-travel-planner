## 배포·자산 확인

정적 공개물은 `gh-pages` 브랜치의 `.nojekyll`, `index.html`, `ongihaeng-hero.webp`로 구성된다. 최신 정적 원본인 `client/public/github-pages/index.html` 및 보조 원본 `docs/index.html`은 공개 `index.html`과 바이트 단위로 일치함을 확인했다. 배너 사진은 기존 풀스택 홈에서 이미 사용하던 프로젝트 관리 자산을 이관한 것이며, 원본 권리 메타데이터의 부재는 `docs/static-visual-assets.md`에 별도 기록했다.

공개 루트 URL은 `200 text/html`, 배너 자산은 `200 image/webp`로 응답했다. 저장소는 Public이며 기본 브랜치는 `qa/phase-1-baseline`, 공개 정적판은 분리된 `gh-pages` 브랜치에서 제공된다. 추적 파일과 도달 가능한 Git 이력에서 환경파일·대표 토큰·개인 키 형식은 발견하지 못했다.

## 기능 검증 상태

정적 HTML의 실행 스크립트를 브라우저 API 모사 환경에서 실행해 지역 필터, 장소 목록 갱신, 로컬 일정 추가, `localStorage` 저장을 확인했다. 로그인·서버 저장·AI 코스·공유·관리자 기능은 의도적으로 정적판에서 제외되며 README와 화면 고지에 명시되어 있다.

6개 장소의 공식 정보 링크는 모두 HTTPS 형식으로 포함되어 있다. 명령행 접근에서 호텔농심·덕구온천·오색그린야드호텔은 `200` 응답을 확인했다. 신세계·아쿠아필드는 서버 측 TLS 연결을 종료했고, 파라다이스 스파 도고는 현재 실행 환경이 인증서 체인을 검증하지 못해 자동 확인하지 못했다. 이 세 건은 링크 자체의 오류로 단정하지 않았으며, 실제 Chromium 렌더링으로 세 주소 모두 브라우저 문서 제목이 반환되는 것을 재확인했다.

공개 GitHub Pages 탭에 실제 연결한 상호작용 QA에서는 초기 장소 6건, 부산 필터 후 장소 2건, HTTPS 공식 링크 6건을 확인했다. 이어 스파랜드 센텀시티를 일정에 추가한 뒤 `localStorage`와 일정 목록에 반영되는지, 다시 삭제한 뒤 빈 일정 상태로 돌아가는지 확인했다. 의도적으로 손상된 일정 저장값을 넣고 새로고침했을 때는 빈 배열로 정규화되고 빈 일정 안내가 표시됐다. 배너 이미지가 실패할 경우에도 CSS의 그라데이션 배경 계층이 남도록 구성했으며, 현재 공개 배너 자산은 `200 image/webp`로 제공된다.

배너 이미지 URL을 존재하지 않는 파일명으로 바꾼 별도 정적 사본을 Chromium으로 렌더링해 자산 실패 상황을 재현했다. 이 경우에도 짙은 녹색 그라데이션 히어로, 흰색 제목·본문, 두 CTA가 정상적으로 표시되어 페이지가 빈 화면이나 읽기 어려운 상태로 전환되지 않음을 확인했다.
