# GitHub Pages 정적판 운영 안내

## 목적

이 정적판은 온기행의 풀스택 서비스 코드와 별도로, **서버 없이도 GitHub Pages에서 동작하는 핵심 여행 탐색판**을 제공합니다. 풀스택 원본은 동일 저장소의 `qa/phase-1-baseline` 브랜치와 관리형 배포 환경에 계속 보존됩니다.

## 제공 기능

| 기능 | 정적판 제공 여부 | 동작 방식 |
|---|---|---|
| 장소 탐색·지역 필터 | 제공 | 브라우저에 포함된 6개 큐레이션 데이터 |
| 공식 정보 이동 | 제공 | 각 장소의 공식 사이트로 외부 링크 |
| 여행 가이드 | 제공 | 브라우저에 포함된 정적 콘텐츠 |
| 간단 여행 목록 | 제공 | `localStorage`에 현재 브라우저만 저장 |
| 로그인·사용자 계정 | 제외 | 서버 인증이 필요함 |
| DB 영속 저장 | 제외 | 서버 DB가 필요함 |
| AI 맞춤 코스 | 제외 | API 키와 서버 호출이 필요함 |
| 공유 링크·관리자 | 제외 | 권한·토큰·DB가 필요함 |

## 배포 구조

GitHub Pages는 전용 `gh-pages` 브랜치의 루트 `index.html`을 발행 원본으로 사용합니다. 풀스택 원본의 유지보수 파일은 `client/public/github-pages/index.html`과 `docs/index.html`에 함께 보관합니다. 정적판 변경 후에는 빌드·검증을 거쳐 이 파일을 `gh-pages` 브랜치의 루트에 반영합니다. 따라서 공개 정적판은 Node 서버, 데이터베이스, 비밀값, 런타임 API에 의존하지 않습니다.

## 업데이트 방법

정적판의 장소 정보나 문구를 수정하려면 `client/public/github-pages/index.html`과 `docs/index.html`을 함께 변경하여 `qa/phase-1-baseline` 브랜치로 반영합니다. 그 뒤 검증된 `index.html`을 `gh-pages` 브랜치 루트에 반영하면 GitHub Pages가 다시 배포합니다. 실제 운영 시간·가격·이용 조건은 정적 데이터로 확정하지 말고 공식 사이트 링크에서 확인하도록 유지합니다.
