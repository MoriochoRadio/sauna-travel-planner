# 실사용 여행 플래너 설계

## 사용자가 완성할 수 있는 여행 정보

각 플랜에는 여행 날짜, 예산 상한, 장소별 시작 시간·예상 비용·체류 시간·메모를 담을 수 있다. 장소 비용 합계와 예산 상한을 함께 보여 주어, 여행 전 대략적인 지출을 점검할 수 있다. 준비 체크리스트는 플랜 단위로 저장되며, 사용자는 완료 상태를 독립적으로 변경할 수 있다.

## 공유 안전성

플랜은 기본적으로 비공개다. 소유자가 공유를 직접 켤 때에만 무작위 토큰이 있는 읽기 전용 링크가 발급된다. 공개 공유 조회는 공유 여부와 토큰을 함께 검사하며, 사용자의 계정 정보·즐겨찾기·방문 기록·AI 추천 이력은 공유하지 않는다. 공유를 중지하면 기존 링크는 더 이상 내용을 반환하지 않는다.

## 데이터 모델

| 대상 | 추가 정보 | 사용 목적 |
|---|---|---|
| 여행 플랜 | 날짜, 예산 상한, 공유 토큰, 공유 상태 | 여행 전체의 계획·공유 상태 관리 |
| 플랜 장소 | 시작 시각, 예상 비용, 체류 시간, 메모 | 하루 동선의 시간·비용·맥락 기록 |
| 체크리스트 | 항목, 완료 여부, 정렬 순서 | 출발 전 준비 관리 |

## 검증 결과

여행 플랜 확장 마이그레이션은 기존 데이터를 삭제하지 않는 컬럼·테이블 추가 방식으로 적용했다. 보호된 tRPC 절차는 서버 컨텍스트의 사용자 ID로 플랜·체크리스트·공유 상태를 처리하며, 17개 테스트와 타입 검사·프로덕션 빌드를 통과했다.
