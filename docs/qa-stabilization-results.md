# 안정화 및 회귀 QA 결과

## 보완 결과

| 항목 | 발견 사항 | 조치 | 검증 결과 |
|---|---|---|---|
| AI 맞춤 코스 | 구조화 응답이 불필요하게 폴백될 수 있었다. | 응답 텍스트 배열·문자열 호환성을 보강하고 GPT에 부적합한 토큰 파라미터를 제거했다. | 실제 API 요청에서 `generatedWith: ai`, 3개 stop 반환을 확인했다. |
| 플랜 메모 | blur 중심 저장은 실제 브라우저 입력 뒤 영속되지 않았다. | 명시적인 저장 버튼과 Enter 저장 동작으로 전환했다. | 로그인 세션에서 메모를 저장한 뒤 데이터베이스에 `QA 회귀 검증 메모`가 기록된 것을 확인했다. |
| 의존성 보안 | 초기 프로덕션 감사에 critical 1건·high 21건이 보고됐다. | tRPC, Axios, Drizzle, AWS SDK, Express, NanoID를 보안 패치 버전으로 올리고 사용하지 않는 차트·채팅·마크다운 템플릿을 제거했다. | 최종 프로덕션 감사는 취약점 0건을 반환했다. |
| 초기 번들 | 지도 모듈이 초기 화면 번들에 포함됐다. | 홈·상세 페이지에서 `TravelMap`을 지연 로드했다. | 지도 청크가 별도 `TravelMap-*.js` 5.93KB로 분리됐고, 주 JavaScript 청크는 796.97KB로 감소했다. |

## 최종 자동 회귀 결과

5개 테스트 파일의 13개 테스트가 통과했고, TypeScript 검사와 프로덕션 빌드도 모두 완료됐다. 지도 지연 로드 뒤에도 대체 지도·실제 지도 연결 양쪽의 렌더링 책임은 동일하게 유지된다.

## 남은 기술 관찰

프로덕션 보안 감사는 통과했다. 다만 Vite는 주 JavaScript 청크가 500KB를 넘는다고 안내하므로, 다음 성능 고도화에서는 추천 스튜디오와 아이콘 묶음의 추가 코드 분할을 검토할 수 있다. 또한 템플릿 유래 Vite peer 경고는 기능 오류가 아니지만, 도구 체인 업그레이드 시 함께 정리하는 것이 좋다.
