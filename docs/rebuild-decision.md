# Sauna Travel Planner 재구축 결정

## 목표

기존 프로젝트의 기획 자산은 살리되, 여행자가 실제로 탐색·저장·계획·되돌아보는 과정을 한 서비스에서 완성할 수 있도록 데이터와 화면 구조를 풀스택 기반으로 재설계한다.

## 유지·이관할 자산

| 자산 | 결정 | 적용 방식 |
|---|---|---|
| 지역, 기간, 취향을 조합하는 코스 생성 문제 정의 | 유지 | 새 추천 입력 모델의 `region`, `purpose`, `mood`, `budget`, `companion`으로 단순화·확장한다. |
| 사우나 → 맛집 → 볼거리의 여행 흐름 | 유지 | 장소 상세의 연계 경험과 플래너 일정 항목으로 분리한다. |
| AI 실패 시에도 동작하는 규칙 기반 코스 | 유지·강화 | AI 응답 실패 시 신뢰도 있는 장소 데이터와 점수 기반 추천을 반환한다. |
| 지도와 공유 가능한 계획 | 유지·확장 | Google Maps 기반 장소 핀·여행 동선, 로그인 사용자의 저장 플랜으로 발전시킨다. |
| 사우나 이용 팁과 웰니스 맥락 | 유지·정교화 | 건강 효능을 단정하지 않고, 연구 유형·출처·주의 문구가 있는 과학 근거 카드로 제공한다. |

## 재설계·교체할 자산

| 기존 한계 | 재구축 결정 |
|---|---|
| 단일 코스 생성 화면 중심 | 탐색, 추천, 상세, 지도, 플래너, 마이페이지로 정보 구조를 분리한다. |
| 장소 데이터가 정적 파일에 섞여 있고 출처·갱신 상태가 불명확 | 장소와 과학 근거를 별도 데이터 모델로 관리하고, 화면에는 마지막 검토 및 면책 정보를 표시한다. |
| 사용자 저장·방문·추천 이력이 URL 공유에 한정됨 | 로그인 사용자별 즐겨찾기, 방문 기록, 여행 플랜, 추천 이력을 데이터베이스에 영속화한다. |
| 데스크톱 폼 중심의 화면 | 하단 탭과 큰 터치 영역을 갖는 모바일 우선 탐색 경험으로 전면 개편한다. |
| 외부 키에 의존하는 지도·검색 흐름 | 내장 지도 연동을 기본으로 사용하고, 실시간 장소 데이터 연동은 출처·갱신 정책을 정한 뒤 추가한다. |

## 데이터 원칙

초기 릴리스에서는 검증·편집한 큐레이션 장소를 명확히 구분해 제공한다. 이용 후기·별점·혼잡도처럼 사용자 생성 정보는 임의로 만들지 않으며, 외부 장소 정보가 추가될 때도 출처와 갱신 시각을 보존한다. 건강 관련 정보는 일반적인 연구 요약과 원문 탐색 경로로 한정하고 개인별 건강 조언이나 효능 보장으로 표현하지 않는다.
