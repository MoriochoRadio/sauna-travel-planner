## 🆕 2026-07-14 전면 재검토 — 발견 및 수정한 버그

라이브 브라우저 테스트 + 코드 리뷰로 아래 버그를 실제로 재현·수정했다 (상세: git log `fix: 코스 생성 버그 수정 + 웜&스파 디자인·데스크탑 레이아웃 전면 개편`).

1. **같은 날 사우나 중복 배치**: `fallback.ts`의 `second` 선정이 `first`를 후보에서 제외하지 않아, 앵커 사우나가 없는 날은 10:00/15:00에 정확히 같은 곳이 두 번 배치됨 → 날짜 내·날짜 간 중복 배제(`seen` Set) 로직으로 수정.
2. **날짜 간 맛집 반복**: 점심/저녁 선정이 순수 점수 정렬이라 매일 동일 결과 → 위와 같은 `seen` 기반 dedup으로 해결.
3. **깨진 문구**: "이어서 another 사우나·온천 코스" — 한글 문장에 영단어 노출 → 수정.
4. **로딩 상태 버그**: 실시간 사우나 미리보기가 `livePreview.length === 0`으로 로딩 여부를 판단해, 결과 0건이면 "불러오는 중…"이 영원히 표시됨 → 별도 `loading` boolean으로 분리.
5. **관리자 안내문 노출**: 지도 키 미설정 시 `"(관리자: Vercel env NEXT_PUBLIC_KAKAO_MAP_KEY 등록 시...)"`가 일반 사용자에게 그대로 노출 → 사용자 관점 문구로 교체.
6. **전국 지도 마커 겹침**: 시군구 230개를 클러스터링 없이 개별 렌더링해 수도권 등에서 마커가 완전히 겹쳐 클릭 불가 → `leaflet.markercluster` 적용.
7. **지도 불필요한 재생성**: `getSigungus(region)`이 렌더마다 새 배열을 반환해 `useEffect` 의존성이 매번 바뀌어, 무관한 입력에도 지도가 통째로 재생성됨 → `useMemo`로 안정화.
8. **디자인 토큰 드리프트**: 문서화된 `bark`/`cream`/`onsen-soft` 대신 일반 Tailwind `gray-*`가 32곳에서 사용되어 웜톤 일관성이 깨짐 → 전량 정리. 배지 컬러도 `docs/design/ui-design.md` 규칙(온천=rose, 사우나=sky, 숙소=violet)에 맞춤.
9. **데스크탑 배경 장식이 사실상 안 보임**: 블러 원 장식이 `-z-10`(음수 z-index)이라 `position:relative`만 있고 z-index 없는 상위 컨테이너의 배경에 완전히 가려짐(스태킹 컨텍스트 버그, 옵션값 문제가 아니었음) → 시그니처 "온천 물결 링" 모티프로 교체하며 `z-0`으로 수정.
10. **데스크탑이 그냥 넓은 모바일 카드였음**: 좁은 중앙 카드 하나만 뜨는 구조는 그대로 두고 장식만 채우던 것을 → 클릭 가능한 스테퍼 + 우측 고정 "선택 요약" 패널의 실질적 2단 레이아웃으로 개편(`docs/design/ui-design.md` §5 참고).

## 🔍 정적 점검 (코드 리뷰)

### 아키텍처
- **엔진 오케스트레이션** (`src/ai/engine.ts`): LLM 우선 → 실패 시 폴백. 카카오 live 데이터(사우나/숙소) 병합.
- **폴백 로직** (`src/ai/fallback.ts`): 다일차(2일+) 또는 옵션 켜짐 시 숙소 자동 포함(매일 다른 숙소). 도메인 규칙 정확.
- **API 라우트** (`src/app/api/course/route.ts`): rate-limit + 하드타임아웃 + 폴백 전환 + `places` 응답 병합.
- **모델 체인** (`src/ai/generate.ts`): 실존 무료 모델 체인, 429 backoff, 파싱 헬퍼 분리(`parse.ts`).

### 데이터
- **seed.ts**: 18곳(17시도 + 경주) curated, 각 region 숙소 1~2곳 포함.
- **kakao.ts**: 로컬 검색 REST API(키 필요, 무료). `hasOnsen`/`hasSauna` 추론, `computeRating`으로 추천지수 산출.
- **sigungu.generated.ts**: 230개 시군구 좌표 자동 생성.
- **sync-tourapi.mjs + sync-tourapi.yml**: 주간 월요일 크론(TOURAPI_KEY 등록 시 동작).

- **키 노출**: 클라이언트 번들에 미노출, 서버 환경변수만 사용.

## ⚠️ 알려진 이슈 / 잔여 과제

1. **무료 모델 rate-limit**: OpenRouter 무료 티어 레이트리밋으로 간헐적 AI 생성 지연. 폴백 견고해 체감 영향 없음.
2. **TOURAPI_KEY 미등록**: GitHub Secrets / Vercel env 미등록 → 주간 동기화 워크플로우 미동작(선택 사항).
3. **카카오 REST 키 교체**: 노출된 키는 추후 교체 예정(현재 사용 중).
4. **다크모드**: 보류 (사용자 선택). 필요시 추가.
5. **저평점 장소 완전 배제는 아님**: `score()`에 추천지수(rating)를 반영해 저평점은 자연 감점되지만, 재고가 부족한 지역(예: 사우나 3곳뿐인 지역)은 중복 배치 방지가 우선이라 낮은 평점(예: 2.9) 장소도 배치될 수 있음. 의도된 동작(반복 배치보다 낫다는 판단)이지만 재고가 늘면 재검토 여지 있음.
