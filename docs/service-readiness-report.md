# 온기행 서비스 준비 판정

## 종합 판정

온기행은 **비공개 베타 사용을 시작할 수 있는 수준**에 도달했다. 사용자는 모바일에서 출처를 확인하며 장소를 탐색하고, AI 코스를 받은 뒤 저장·일정·예산·체크리스트·공유 링크가 있는 개인 플랜을 만들 수 있다. 운영자는 별도 관리 화면에서 장소 출처·검증 상태와 사용자 플랜의 상태·공유·내부 검토 메모를 관리한다.

공개 서비스로 넓히기 전에는 현재 카탈로그의 모든 장소를 공식 출처로 재확인하고, 초안 상태 장소의 운영 정보 공개 범위를 유지해야 한다. 따라서 이 판정은 **제한된 장소 범위의 비공개 베타 준비 완료**이며, 무제한 공개 출시 선언은 아니다.

## 사용자가 실제로 할 수 있는 일

| 사용자 흐름 | 준비 상태 | 핵심 안전 장치 |
|---|---|---|
| 장소 탐색·필터·상세 확인 | 준비됨 | 지역·분위기·시설·예산·동행 필터와 출처·검증일 표기 |
| AI 맞춤 코스 | 준비됨 | 큐레이션 카탈로그 밖의 사실을 만들지 않고 실패 시 안전한 폴백 제공 |
| 개인 여행 플랜 | 준비됨 | 날짜·예산·장소별 시간·비용·체류·메모·체크리스트 관리 |
| 공유 플랜 | 준비됨 | 기본 비공개, 소유자가 공유를 켤 때에만 토큰형 읽기 전용 링크 발급 |
| 신뢰 콘텐츠 | 준비됨 | 공식 정보 확인·큐레이션 초안 상태를 구분하고 방문 전 공식 확인 안내 |
| 운영 관리 | 준비됨 | 관리자 역할만 장소 출처·검증 상태·플랜 상태·공유·내부 메모를 저장 가능 |

## 출시 전 필수 운영 절차

1. 운영자는 장소 관리 화면에서 `큐레이션 초안`인 장소를 우선 검토하고, 공식 URL·검증일을 저장한다.
2. 실제 공개 전용 계정으로 플랜 생성부터 공유 링크 열람까지 마지막 한 차례의 사용자 수용 테스트를 수행한다. 개발 미리보기의 공유 URL은 외부 공개용이 아니므로 게시 환경에서 다시 확인한다.
3. 베타 참여자에게는 운영 시간·요금·이용 조건이 변동될 수 있으므로 출처 링크를 다시 확인하도록 안내한다.

## 다음 고도화 우선순위

이후에는 공공 관광 데이터와 시설 공식 채널을 정기 점검하는 운영 절차, 장소 데이터의 지역 확장, 초기 공통 JavaScript 청크의 추가 최적화를 순서대로 진행하는 것이 적절하다. 사용자 후기나 별점은 실제 수집·검수 체계가 준비되기 전에는 도입하지 않는다.
