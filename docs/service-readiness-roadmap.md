# 온기행 서비스 준비 로드맵

## 서비스 준비 판단 기준

실제 사용자가 서비스를 신뢰하려면 단순히 화면이 작동하는 것만으로는 부족하다. 장소 정보의 출처·검증일, 계획을 끝까지 완성할 수 있는 플래너, 개인 데이터의 안전한 관리, 운영자가 변경을 통제할 수 있는 도구가 함께 필요하다.

| 축 | 서비스 준비 기준 | 이번 고도화의 우선순위 |
|---|---|---|
| 콘텐츠 신뢰 | 주요 장소마다 공식 출처·검증일·방문 전 확인 경로 제공 | 최우선 |
| 여행 완결성 | 날짜, 일정 순서, 예상 비용, 준비물, 공유 가능한 플랜 | 최우선 |
| 개인화 | 저장·방문 기록에서 다음 여행을 이어 볼 수 있음 | 높음 |
| 운영성 | 관리자 승인·수정·검증 상태·출처 관리 | 높음 |
| 안정성 | 역할 권한, 빈·오류 상태, 모바일·성능·보안 QA | 최우선 |

## 단계별 확장

1. **신뢰 콘텐츠 레이어**에서는 공식 링크와 검증 상태를 카탈로그·상세 화면에 반영하고, 부산 중심의 출처 기반 큐레이션을 먼저 완성한다.
2. **여행 완결 레이어**에서는 플랜 날짜, 예상 예산, 체크리스트, 일정별 메모와 공개 링크를 도입한다.
3. **운영 레이어**에서는 관리자만 장소 정보·출처·검증 상태를 관리하도록 하고, 초안 장소와 공개 장소를 구분한다.
4. **서비스 준비 검증**에서는 비로그인·일반 사용자·관리자 역할로 권한을 분리해 실제 저장·공유·수정 흐름을 검사한다.

## 비범위 원칙

이 단계에서는 출처 없는 영업 정보, 실제 사용자 후기의 임의 생성, 의료 효능의 확정적 표현, 개인 위치의 자동 수집을 제공하지 않는다. 예약·결제는 각 시설의 공식 경로로 연결하며, 플랫폼이 직접 예약 가능하다고 표현하지 않는다.
