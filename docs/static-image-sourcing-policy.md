# 정적판 이미지 소싱·출처 표기 정책

**작성일:** 2026-08-14  
**적용 범위:** `client/public/github-pages/index.html`, `docs/index.html`, `gh-pages` 공개 정적판

## 목적

온기행 정적판은 장소의 분위기를 보여 주기 위해서라도 권리 상태가 불분명한 사진을 사용하지 않는다. 시설 공식 웹사이트에 공개된 이미지는 별도 재사용 허가 또는 명시된 라이선스가 확인되지 않는 한, 정적판에 복제·재배포하지 않는다. 이 원칙은 상업화 여부와 관계없이 적용한다.

## 허용 기준

| 자산 유형 | 정적판 사용 조건 | 필수 표기 |
| --- | --- | --- |
| 포토코리아의 KOGL 1유형 이미지 | 개별 이미지에 KOGL 표시, 식별 정보와 사용 범위를 확인한 경우 | `© 한국관광공사-촬영자`, 원본 URL, KOGL 유형 |
| 지방관광 아카이브 이미지 | 해당 아카이브에서 라이선스와 사용 조건이 명시된 경우 | 제공기관, 원본 URL, 라이선스 유형 |
| 시설 제공 이미지 | 시설 또는 권리자로부터 재사용 허가를 기록한 경우 | 시설명 또는 권리자, 허가·원본 URL |
| 직접 제작한 일러스트·아이콘 | 제작 이력과 원본 파일을 보관한 경우 | 별도 표기 불필요, 필요 시 제작 주체 표기 |

포토코리아는 사진별 KOGL 표시에 따라 사용 조건이 달라지며, KOGL 표시가 없는 사진은 한국관광공사 기준을 따르고 별도 문의가 필요하다고 안내한다.[1] 공공데이터포털의 관광사진 정보 API는 포토코리아 사진을 KOGL 1유형 콘텐츠로 소개하지만, 실제 반영 전에는 개별 자산의 라이선스 표기를 다시 확인한다.[2]

> **현재 결론:** 6개 상업 시설의 사진은 재사용 권한이 확인된 개별 자산을 아직 확보하지 않았다. 따라서 장소와 무관한 대체 사진이나 출처가 모호한 공식 사이트 캡처를 추가하지 않는다.

## 자산 등록 전 검증 항목

새 사진을 반영하려면 아래 필드를 함께 기록한다. 하나라도 비어 있으면 공개 정적판에 포함하지 않는다.

```ts
type StaticImageAttribution = {
  url: string;
  alt: string;
  sourceUrl: string;
  attribution: string;
  license: "KOGL-1" | "permission-recorded" | "self-created";
  verifiedAt: string;
};
```

서울관광재단도 일반 페이지의 모든 사진을 자유롭게 사용할 수 있는 것은 아니며, 관광 아카이브에서 제공되는 자료만 저작권 표시에 따라 사용할 수 있다고 안내한다.[3] 따라서 화면에 보인다는 사실만으로 재사용 가능하다고 간주하지 않는다.

## 운영 절차

| 단계 | 수행 내용 | 공개 전 확인 |
| --- | --- | --- |
| 1. 후보 수집 | 공공 아카이브·권리자 제공 자료에서 장소 또는 인근 여행 맥락에 맞는 후보를 찾는다. | 원본 URL과 촬영자·제공기관 확보 |
| 2. 권리 판정 | 개별 자산의 라이선스·상업 이용·변경 가능 여부를 확인한다. | 허용 기준 충족 여부 기록 |
| 3. 콘텐츠 검수 | 장소를 오인하게 하는 사진인지, 인물 초상권·상표 문제가 없는지 확인한다. | 대체 텍스트와 캡션 작성 |
| 4. 반영·감사 | 원본 URL과 출처를 카드 또는 출처 영역에 노출한다. | `verifiedAt` 갱신 및 배포 QA |
