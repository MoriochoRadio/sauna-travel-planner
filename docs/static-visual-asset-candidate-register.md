# 정적판 시각 자산 후보 등록부

**조사일:** 2026-08-14  
**판정:** 이번 조사에서는 정적판에 즉시 반영할 수 있는 개별 사진 자산이 확인되지 않았다.

| 장소 | 확인 경로 | 결과 | 반영 판정 |
| --- | --- | --- |
| 덕구온천 리조트 | [포토코리아 `덕구온천` 검색](https://phoko.visitkorea.or.kr/en/media/mediaList.kto?keyword=%EB%8D%95%EA%B5%AC%EC%98%A8%EC%B2%9C) | 검색 결과 0건 | 보류 |

| 파라다이스 스파 도고 | [포토코리아 `도고온천` 검색](https://phoko.visitkorea.or.kr/en/media/mediaList.kto?keyword=%EB%8F%84%EA%B3%A0%EC%98%A8%EC%B2%9C) | 검색 결과 0건 | 보류 |
| 스파랜드·허심청·아쿠아필드 고양 | 시설 공식 웹사이트 | 게시 이미지의 재배포 허가·개별 라이선스가 확인되지 않음 | 보류 |

포토코리아는 KOGL 표시가 있는 사진은 해당 조건에 따라 사용할 수 있지만, 표시가 없는 사진은 별도 기준과 문의 절차가 필요하다고 안내한다.[1] 따라서 시설 공식 페이지에 표시된 사진을 단순 복제하거나, 장소와 무관한 분위기 사진으로 대체하지 않는다.

## 다음 후보 확보 방식

| 우선순위 | 방법 | 반영 전 증빙 |
| --- | --- | --- |
| 1 | 포토코리아·지역 관광 아카이브에서 개별 KOGL 1유형 자산 검색 | 원본 URL, 자산 식별자, 촬영자·제공기관, 라이선스 표시 |
| 2 | 시설 운영사에 웹·GitHub Pages 재배포 범위의 서면 또는 전자 허가 요청 | 허가 기록, 사용 기간·매체·수정 가능 범위 |
| 3 | 장소가 아닌 여행 맥락을 설명하는 자체 제작 비사진 일러스트 | 원본 제작 파일과 대체 텍스트 |

사진을 반영할 때에는 `docs/static-image-sourcing-policy.md`의 `url`, `alt`, `sourceUrl`, `attribution`, `license`, `verifiedAt` 필드를 모두 채운다. 하나라도 확인되지 않으면 후보 등록 상태를 유지하고 공개 정적판에는 포함하지 않는다.
