# GitHub Pages 정적판 시각 자산 기록

## 확인 결과

현재 풀스택 온기행 소스에서 사용자에게 노출되는 여행 사진은 홈 히어로의 **산속 노천 온천 배너** 한 건이다. 해당 이미지는 프로젝트 관리형 저장소의 `sauna-journey-hero_e1e8dfeb.jpg` 경로로 참조되고 있었으며, 정적판에는 동일한 프로젝트 자산을 `gh-pages` 브랜치의 `ongihaeng-hero.webp`로 이관했다.

| 항목 | 확인 내용 | 정적판 반영 |
|---|---|---|
| 홈 히어로 | 기존 `Home.tsx`의 `/manus-storage/sauna-journey-hero_e1e8dfeb.jpg` | `gh-pages/ongihaeng-hero.webp` 배경으로 복원 |
| 장소 카드 | 기존 `PlaceCard.tsx`는 장소 사진을 사용하지 않음 | 새 사진을 임의로 추가하지 않음 |
| 장면 카드 | 기존 화면도 CSS 그라데이션 기반 | 그라데이션 디자인 유지 |

## 출처와 사용 유의사항

배너는 기존 프로젝트에서 이미 사용 중인 관리형 자산을 그대로 이관한 것이다. 그러나 현재 저장소에는 원 촬영자·외부 라이선스·생성 이력을 명시한 메타데이터가 남아 있지 않다. 따라서 제3자 상업 사용, 광고 집행, 별도 재배포 전에는 원본 권리 또는 생성 기록을 확인해야 한다.

장소별 사진은 기존 프로젝트에 없었으므로, 공식 사이트·관광 기관·제3자 플랫폼의 사진을 무단으로 복사하지 않았다. 향후 장소 사진을 추가할 때에는 각 이미지의 사용 허가·저작자·출처 URL을 함께 기록한다.

## 배포 위치

GitHub Pages는 `gh-pages` 브랜치의 루트 파일을 공개한다. 따라서 실제 공개 페이지의 `index.html`과 `ongihaeng-hero.webp`는 해당 브랜치에 보관된다. 풀스택 소스 브랜치에는 정적판 HTML 원본과 이 기록 문서만 보관한다.
