# Visual QA 기록

## 검토 범위

2026-08-12에 홈, 장소 상세, 마이페이지를 데스크톱(1280px)과 모바일(390px) 화면에서 확인했다.

## 확인된 결과

홈 화면은 히어로의 어두운 온천 이미지와 밝은 큐레이션 카드의 대비가 명확하며, 모바일에서 필터·카드·AI 코스 입력이 한 열로 자연스럽게 재배치된다. 장소 상세 화면은 장소 정보, 지도, 이용 팁, 과학 근거, 주변 연계 정보를 위에서 아래로 읽는 구조가 모바일에서 유지된다. 마이페이지는 비로그인·초기 상태에서도 저장 장소, 플랜, 방문 기록, 추천 이력의 의미가 명확한 빈 상태를 제공한다.

Google 지도 스크립트를 로드하지 못하는 환경에서는 빈 지도가 보이지 않도록, 장소 순서와 동선을 표현하는 대체 지도 화면을 제공하도록 보완했다. 실제 배포 환경에서는 내장 지도 연동을 우선 사용하며, 대체 지도는 네트워크 실패에 대비한 점진적 기능 저하 방식이다.

## 후속 확인 항목

로그인 후 즐겨찾기, 플랜 생성, 방문 기록, 추천 이력 저장 흐름을 실제 사용자 세션에서 확인한다. 모든 장소 데이터는 초기 큐레이션 데이터이므로, 운영 전 공식 출처·갱신 시각·정확한 주소를 바탕으로 장소 데이터를 확장·검수한다.
